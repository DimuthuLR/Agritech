# AgriTech System

An AI-assisted precision agriculture platform for small-to-medium farms.

## Stack
- Backend: FastAPI (Python 3.12.7)
- DB: PostgreSQL 16 + TimescaleDB
- Cache/Queue: Redis 7
- IoT: MQTT (Mosquitto), farmOS webhooks
- AI: Qwen2.5 via vLLM, Gemini Vision
- Frontend: Vue 3 + Vite + TypeScript

## Layout
- `backend/` — FastAPI application
- `frontend/` — Vue 3 SPA
- `docs/` — architecture and operations docs
